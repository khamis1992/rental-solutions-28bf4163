# دليل إعداد Google Vision API Key

## نظرة عامة

Google Vision API يمكّن النظام من:
- قراءة النصوص من صور البطاقات الشخصية القطرية
- استخراج بيانات العقود من الصور
- معالجة الفواتير الممسوحة ضوئياً
- تحليل المستندات بصرياً

## الخطوة 1: إنشاء مشروع في Google Cloud

### 1.1 إنشاء حساب Google Cloud
1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com/)
2. سجل دخول بحساب Google الخاص بك
3. إذا كنت مستخدم جديد، ستحصل على رصيد مجاني $300

### 1.2 إنشاء مشروع جديد
1. انقر على "Select a project" في أعلى الصفحة
2. انقر على "New Project"
3. أدخل اسم المشروع: `rental-management-system`
4. انقر على "Create"

## الخطوة 2: تفعيل Vision API

### 2.1 تفعيل الخدمة
1. في Google Cloud Console، اذهب إلى "APIs & Services" > "Library"
2. ابحث عن "Vision API"
3. انقر على "Cloud Vision API"
4. انقر على "Enable"

### 2.2 إعداد الفوترة (مطلوب)
1. اذهب إلى "Billing" في القائمة الجانبية
2. ربط بطاقة ائتمان (للتحقق من الهوية)
3. **ملاحظة**: الاستخدام الأساسي عادة مجاني ضمن الحدود الشهرية

## الخطوة 3: إنشاء API Key

### 3.1 إنشاء Credentials
1. اذهب إلى "APIs & Services" > "Credentials"
2. انقر على "Create Credentials"
3. اختر "API Key"
4. انسخ المفتاح الذي تم إنشاؤه

### 3.2 تأمين API Key (مهم)
1. انقر على اسم API Key للتعديل
2. في "API restrictions":
   - اختر "Restrict key"
   - اختر "Cloud Vision API"
3. في "Application restrictions" (اختياري):
   - اختر "HTTP referrers" 
   - أضف نطاق موقعك
4. انقر على "Save"

## الخطوة 4: إضافة المفتاح إلى Supabase

### 4.1 في Supabase Dashboard
1. اذهب إلى مشروع Supabase الخاص بك
2. انقر على "Project Settings" في الشريط الجانبي
3. انقر على "Edge Functions"
4. في قسم "Environment Variables":
   - Variable name: `GOOGLE_VISION_API_KEY`
   - Value: المفتاح الذي نسخته من Google Cloud
5. انقر على "Save"

### 4.2 إعادة نشر Edge Functions
```bash
# في Terminal
supabase functions deploy process-google-vision
supabase functions deploy process-invoice-ocr
```

## الخطوة 5: اختبار التكامل

### 5.1 في النظام
1. اذهب إلى لوحة التحكم
2. في قسم "تشخيص الخدمات"
3. انقر على "تحديث"
4. تأكد من أن "Google Vision OCR" يظهر كـ "نشط" ✅

### 5.2 اختبار عملي
1. اذهب إلى "العملاء" > "إضافة عميل جديد"
2. جرب رفع صورة بطاقة شخصية قطرية
3. تأكد من استخراج البيانات تلقائياً

## التكاليف والحدود

### الاستخدام المجاني الشهري
- **1,000 طلب أول** شهرياً: مجاني تماماً
- **من 1,001 إلى 5,000,000**: $1.50 لكل 1,000 طلب
- **أكثر من 5,000,000**: $0.60 لكل 1,000 طلب

### تقدير التكلفة للنظام
- **نظام صغير** (100 عميل/شهر): مجاني
- **نظام متوسط** (500 عميل/شهر): مجاني
- **نظام كبير** (2000 عميل/شهر): ~$1.50/شهر

## استكشاف الأخطاء

### خطأ "API key not valid"
- تأكد من نسخ المفتاح بالكامل
- تحقق من تفعيل Vision API
- تأكد من عدم وجود مسافات زائدة

### خطأ "This API method requires billing"
- أضف بطاقة ائتمان في Google Cloud
- تفعيل الفوترة مطلوب حتى للاستخدام المجاني

### خطأ "API calls quota exceeded"
- تحقق من استهلاك API في Google Cloud Console
- فكر في تحسين عدد الطلبات

## البدائل إذا لم ترد استخدام Google Vision

النظام يعمل بدون Google Vision ويستخدم:
- **بيانات تجريبية**: لأغراض العرض والاختبار
- **إدخال يدوي**: يمكن إدخال بيانات العملاء يدوياً
- **OCR محلي**: يمكن تطوير حل OCR محلي لاحقاً

## الأمان والخصوصية

### حماية API Key
✅ المفتاح محفوظ في Supabase Edge Functions (آمن)  
✅ لا يظهر في الكود الأمامي  
✅ مقيد على Vision API فقط  
✅ يمكن إلغاؤه وإعادة إنشاؤه في أي وقت  

### خصوصية البيانات
✅ الصور تُعالج مؤقتاً ولا تُحفظ في Google  
✅ البيانات المستخرجة تُحفظ في قاعدة البيانات المحلية  
✅ يمكن تعطيل الخدمة في أي وقت
