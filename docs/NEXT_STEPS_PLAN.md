## 🔧 التفاصيل التقنية

### نمط التحديث المعياري

#### 1. إضافة الاستيرادات
```typescript
import { useErrorHandler } from '@/hooks/useErrorHandler';
import { ErrorDisplay } from '@/components/common/ErrorDisplay';
import { ErrorBoundary } from '@/components/common/ErrorBoundary';
```

#### 2. إضافة Hook
```typescript
const { error: errorState, handleError, clearError } = useErrorHandler();
```

#### 3. تحديث العمليات
```typescript
const handleOperation = async () => {
  try {
    clearError();
    // العملية الأساسية
  } catch (error) {
    handleError(error, {
      showToast: true,
      logError: true,
      context: { page: 'page-name', action: 'operation-name' }
    });
  }
};
```

#### 4. إضافة ErrorDisplay
```typescript
{errorState.hasError && (
  <ErrorDisplay
    error={errorState.error}
    variant="card"
    showRetry={true}
    onRetry={() => {
      clearError();
      handleOperation();
    }}
  />
)}
```

#### 5. تطبيق ErrorBoundary
```typescript
<ErrorBoundary 
  context={{ page: 'page-name', component: 'component-name' }}
  showRetry={true}
  showBack={false}
>
  <MyComponent />
</ErrorBoundary>
```
